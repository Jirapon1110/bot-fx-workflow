คู่มือการใช้งาน bot-fx-workflow

เครื่องมือบรรทัดคำสั่งที่ดึงอัตราแลกเปลี่ยนถัวเฉลี่ยถ่วงน้ำหนักระหว่างธนาคาร THB / USD จาก Bank of Thailand API ล่าสุด 20 วันทำการ แล้วเก็บต่อท้าย (append) ลงฐานข้อมูล SQLite

1. สิ่งที่ต้องมี

  • uv (ติดตั้งตาม docs.astral.sh/uv)
  • API token ฟรีจาก portal.api.bot.or.th (สมัครสมาชิก → สร้าง Application → subscribe ผลิตภัณฑ์ Exchange Rates → คัดลอก token)

2. ติดตั้งและตั้งค่า

git clone https://github.com/Jirapon1110/bot-fx-workflow.git
cd bot-fx-workflow
uv sync
copy .env.example .env      # macOS/Linux: cp .env.example .env

เปิดไฟล์ .env แล้วแก้ค่า:

ตัวแปรจำเป็นความหมาย
BOT_API_TOKENใช่token จาก portal
APPLICANT_NAMEใช่ชื่อภาษาอังกฤษ (ตัวอักษร ตัวเลข _ - เท่านั้น) ใช้ตั้งชื่อไฟล์ฐานข้อมูล
BOT_DB_DIRไม่โฟลเดอร์เก็บฐานข้อมูล (ค่าเริ่มต้น .venv)

ห้าม commit ไฟล์ .env หรือ token ลง repository (ถูกตั้งค่าไว้ใน .gitignore แล้ว)

3. วิธีรัน

รันในโฟลเดอร์โปรเจกต์ (โฟลเดอร์ที่มีไฟล์ .env):

uv run bot-fx

ตัวอย่างผลลัพธ์ (ระบบพิมพ์ path ของฐานข้อมูลแบบเต็ม):

Fetched 20 points (2026-10-21 .. 2026-11-18); inserted 20 new rows into C:\...\bot-fx-workflow\.venv\bot_api_daily_Name.db

รันซ้ำได้ปลอดภัย: ระบบเพิ่มเฉพาะวันที่ยังไม่มีในฐานข้อมูล (รันครั้งที่สองจะขึ้น inserted 0 new rows)

4. ผลลัพธ์ในฐานข้อมูล

ไฟล์: .venv/bot_api_daily_{APPLICANT_NAME}.db ตาราง daily_ref_rate

คอลัมน์ความหมาย
period (PK)วันที่ (ISO YYYY-MM-DD)
rateบาทต่อ 1 ดอลลาร์สหรัฐ
currency_pairคงที่ THB/USD
fetched_atเวลา (UTC) ที่บันทึกแถวนั้น

ตัวอย่างการดูข้อมูล:

uv run python -c "import glob, sqlite3; f = glob.glob('.venv/bot_api_daily_*.db')[0]; c = sqlite3.connect(f); print(f, c.execute('select * from daily_ref_rate order by period desc limit 5').fetchall())"

5. ข้อควรรู้

  • "20 วัน" ตีความเป็น 20 data point ล่าสุด เพราะ API มีเฉพาะวันทำการ
  • API จำกัดช่วงวันที่ต่อคำขอ (ทดสอบเมื่อ 2026-11-19: 31 วันผ่าน, 35 วันไม่ผ่าน) โปรแกรมจึงดึงย้อนหลังเป็นช่วง ๆ ละ 30 วันให้อัตโนมัติ
  • ถ้าลบหรือสร้างโฟลเดอร์ .venv ใหม่ ไฟล์ฐานข้อมูลที่อยู่ข้างในจะหาย ให้สำรองไว้หรือตั้ง BOT_DB_DIR ไปที่อื่น
  • ตัวแปรที่ตั้งไว้ใน shell อยู่แล้วจะมีผลก่อนค่าใน .env ถ้าชื่อไฟล์ฐานข้อมูลหรือ token ไม่ตรงที่ตั้งใจ ให้เช็กตัวแปรเหล่านั้น

6. แก้ปัญหาเบื้องต้น

อาการสาเหตุ / วิธีแก้
BOT_API_TOKEN is not setยังไม่ได้ตั้งค่าใน .env หรือรันนอกโฟลเดอร์โปรเจกต์ (ให้ cd เข้าโฟลเดอร์โปรเจกต์ก่อนรัน)
BOT_API_TOKEN must be plain printable ASCIItoken มีอักขระแปลก ช่องว่าง หรือยังเป็นข้อความตัวอย่าง ให้คัดลอก token จาก portal ใหม่
APPLICANT_NAME must be set…ตั้งชื่อเป็นภาษาอังกฤษ ไม่มีช่องว่างหรืออักขระพิเศษ
BOT API returned HTTP 401/403token ผิด/หมดอายุ หรือยังไม่ได้ subscribe ผลิตภัณฑ์ Exchange Rates
HTTP 400รูปแบบวันที่หรือช่วงวันที่ไม่ถูกต้อง (โปรแกรมจัดการให้เอง ถ้าพบให้แจ้งผู้พัฒนา)
Only N data points availableAPI คืนข้อมูลน้อยกว่า 20 แถวในช่วงที่ย้อนดู ข้อมูลที่ได้ถูกบันทึกแล้ว

7. ทดสอบ

uv run pytest

เทสต์ทำงานแบบออฟไลน์ (จำลอง HTTP) ไม่ต้องใช้ token
